# ECE SRIP 2022

**PCD_from_image_and_depth_map.py** reads the sample images and depth maps from the *data* directory and converts them into point clouds representing a 3D human model.

The **sample_images** directory contains 1 sample image and its corresponding depth map taken from the D415 and the D435 camera. This is used to verify that the camera calibration process works correctly.

The **Camera** directory contains the classes that facilitate 3D reconstruction.

**get_sample_video.py** takes a sample video recording from both the D415 and the D435 cameras, and stores the videos in .bag files. 

**get_calibration_images.py** takes 12 images from each camera of a chessboard pattern (6x9), and saves these images.

**stereocalibrate.py** reads the images generated by the previous program and finds the intrinsic and extrinsic parameters. These are stored in *data/THuman/calibration_data.json*

**combine_pcd.py** uses the calibration data from the previous program, to combine point clouds generated from the sample images.

**get_intrinsics.py** helps obtain the intrinsic parameters defined by the Intel Realsense SDK.

**scalable_capturing.py** detects any connected Intel RealSense Cameras and captures a color image and corresponding depth map from each camera (and this works for any arbitrary number of cameras). The images and depth maps are saved in a directory identified by the serial number for the camera. This helps obtain a sample image and depth map from each camera.

**scalable_calibration_images.py** detects any connected Intel RealSense cameras and collects 30 calibration images from each camera, storing each image in a directory identified by the camera's serial number.

**scalable_stereocalibration.py** performs camera calibration on all pairs of cameras, and stores all the calibration data in *configuration_parameters.json*.
